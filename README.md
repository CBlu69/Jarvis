# جارویس آفلاین

یک PWA فارسی که **شنیدن** (Whisper) و **فکر کردن** (مدل زبانی) را داخل خود گوشی انجام می‌دهد.
مدل‌ها فقط بار اول دانلود می‌شوند (حدود ۱ تا ۲ گیگابایت)؛ بعد از آن بدون اینترنت کار می‌کند.

## فایل‌ها (همه باید کنار هم باشند)

- `index.html` — رابط و منطق اصلی
- `asr-worker.js` — تشخیص گفتار (Whisper)
- `llm-worker.js` — مغز زبانی (WebLLM)
- `sw.js` — کش برای کار کردن بدون اینترنت
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png` — نصب به‌صورت اپ

## راه‌اندازی (GitHub Pages)

1. همه‌ی فایل‌ها را در یک repo آپلود کن (در ریشه، کنار هم).
2. Settings ← Pages ← Branch: `main` ← Save.
3. آدرس `https://اسمت.github.io/اسم-repo/` را با **Chrome** باز کن (باید https باشد).
4. «فعال‌سازی» را بزن، اجازه‌ی میکروفون را بده و **با Wi‑Fi** صبر کن تا مدل‌ها دانلود شوند.
5. از منوی Chrome ← «Add to Home screen» تا مثل اپ نصب شود.
6. یک بار حالت هواپیما را روشن کن و امتحان کن که آفلاین بالا می‌آید.

## نکته‌ها

- مغز زبانی WebGPU می‌خواهد. اگر گوشی‌ات ندارد، فقط دستورهای ساده کار می‌کنند (ساعت، تاریخ، تایمر، یادداشت).
- اگر مغز بالا نیامد، در تنظیمات مدل را به «Llama 1B» یا «Qwen 1.5B» تغییر بده.
- جواب صوتی به صدای فارسی نصب‌شده روی گوشی نیاز دارد (تنظیمات اندروید ← Text-to-speech). بدون آن، جواب‌ها فقط نوشته می‌شوند.
- تایمر فقط تا وقتی برنامه باز است زنگ می‌زند.
- مدل‌های کوچک آفلاین به همه‌ی سؤال‌ها جواب درست نمی‌دهند و خبر روز ندارند.
